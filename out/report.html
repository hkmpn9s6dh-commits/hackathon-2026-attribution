Discipline is a choice

Behavioural attribution measures the leash, not the hand — and the leash is for sale
Submission to the Agent Attribution Hackathon (Apart Research, 11–13 December 2026) · Track 2, Attribution · Code and every number in this report: github.com/hkmpn9s6dh-commits/hackathon-2026-attribution · 20 November 2026
Abstract. A responder arriving at an agent incident needs a fact the logs do not contain: is a human steering this, and how tightly? We build a replayable testbed from the five actor types in the sprint brief, two observable channels — when the agent acts and what it touches — and five evasion levels, with 600 traces per level and grouped five-fold cross-validation. Timing recovers how tightly a human is in the loop (ρ = 0.95). It appears to recover intent too (AUC = 0.90) — until the leash is held fixed, at which point it falls to chance (AUC = 0.48). The apparent intent signal is the leash wearing intent's clothes. Target choice shows the mirror image: intent AUC = 0.95, leash ρ = 0.10 once intent is fixed. Under disguise the two channels behave differently. An autonomous agent that waits like a supervised one becomes indistinguishable from one (AUC 1.00 → 0.51) at a measured cost of 60 seconds per action; a human who auto-approves pays nothing and erases the channel outright. A detector fitted on the honest fleet does not decay — it inverts (ρ = -0.72). Camouflaged payloads collapse the target channel (AUC 0.95 → 0.53) for 63% of the actor's sensitive surface. Behaviour can tell you to go and look. It cannot tell you who to call.

1. The question, and why it is not academic

When an agent shows up in an incident — a supply-chain commit, an escaped process, a run that spent money — the first question a responder asks is not "which model" but "who, if anyone, is steering it". A human reachable by phone, a human who has not opened the logs in a week, and an agent nobody is watching call for three different responses: contact, escalation, containment. Today the three look alike from the outside, because in all three cases the text was written by the AI. Text detectors and assistant-fingerprinting tools inherit that blindness: they classify the model, not the hand on the leash [1,3].

The sprint brief proposes three ways out: causal timing, identity probes, and vendor attestation [2]. This report is about the first, and about what happens to it when the observed party knows it is being observed. We do not have the incident logs the organisers will score against, and we do not pretend to: our claim is narrower and, we think, more useful — that "can behaviour attribute an actor?" is a question with a measurable answer and a price tag, and that the answer is uncomfortable for anyone planning to deploy such a classifier.

2. Testbed: what is observable, and what is only latent

We implement the brief's five actor types (Table 1). What makes the problem hard is not the number of classes. It is that the classes differ along two axes — how tight the leash is (ordinal: 0 = nobody steering, 3 = a human on every step) and whether the human is benign (a binary we never observe) — and the two axes are entangled in the label in a way that flatters naive evaluation (Section 4.3).

A trace is a sequence of events over a 3–5 hour window: inbound messages, and actions carrying a tool (edit, read, shell, commit, net), a target path, a payload size and a shell-chain length. An action either waits for a human — it lands a human-latency interval after its scheduled tick, usually after a request message — or it does not. The share of actions that wait is the mixture weight p. It is the only thing that separates the actor types in the timing channel, and it is what a responder means by "tightly supervised".

Three design decisions carry the report. First, timing and content are generated by separate random streams: with one stream, drawing a different target file shifts every later draw and leaks the label into the timing, and a first version of this testbed did exactly that (a timing-only classifier scored AUC 0.90 on intent for no reason a responder could act on). Second, no event carries a label — there is no approved_by field, because a detector that can read it is not a detector. Third, tools follow targets, not labels: a workflow file gets edited, a key gets read. Wherever we allowed a class signature to leak into a second statistic, it did, and the leakage always looked like a great result.

3. Method

Features. Thirteen timing features (inter-arrival median and 90th percentile, coefficient of variation, binned entropy, Fano factor over minute buckets, phase concentration on the 60 s grid, latency after an inbound message at three cut-offs, coverage, share of gaps over five minutes) and ten target features (share of actions on sensitive paths — CI workflows, keys, registry config, install hooks — directory entropy, target diversity, tool mix, shell-chain length, edit size). No feature sees a label, an org id or a scenario id.

Models. Multinomial logistic regression and a small gradient-boosted tree ensemble (depth 2, 45 rounds, deterministic), each with three heads: the five-way label, the ordinal leash, the intent flag. Trees are included because a linear model could understate what a flexible detector can do; in practice the two agree closely, which is itself reassuring — the ceiling here is the channel, not the model.

Evaluation. Five-fold cross-validation grouped by org, never by trace: an actor's other traces are never in the training fold, so a score is a statement about an actor the model has not met. Chance is measured, not assumed — labels are permuted across orgs five times (ρ = -0.01, AUC = 0.48).

Evasion ladder. Four levels, each a plausible move by one side (Table 2). Every level is generated from the same seeds as L0, so the same actor does the same job with a different discipline: the comparison is paired, and only the discipline changes.

Transfer and matched pairs. At each level we also score a detector frozen at L0 — the deployment that actually happens, a model fitted on last quarter's incidents. And because our central claim is about what a channel can identify at all, we run matched comparisons: two classes that share a leash for intent, three classes that share intent for the leash, and two pairs that share a mixture weight outright.

4. Results

4.1 Five-way accuracy is the wrong scoreboard

On the honest fleet the five-way problem is nearly solved: macro-F1 0.93, with most residual error between the two classes that share a leash setting (Figure 2). That number is a trap of a different kind. It says a classifier can reproduce the brief's taxonomy on data from the same generator. It says nothing about whether the quantity is stable, whether the channel is doing the work, or what happens when the observed party stops cooperating — which is the rest of this section.

4.2 The clock knows the leash; the file paths know the hand

Figure 3A is the clean result. Timing recovers the leash almost perfectly (ρ = 0.95), and target features are nearly blind to it (ρ = 0.17). Figure 3C is the same comparison for intent with the leash held fixed: targets separate benign from non-benign actors at AUC 0.97, timing at 0.48 — chance.

This is not a modelling artefact; it follows from what the classes are. Timing sees a mixture: what share of actions waited, and for how long. That share describes an arrangement, and an arrangement is compatible with any intent. Targets see a choice: which files an actor reaches for at three in the morning. That choice describes a job. A responder asking "is anyone watching this" should read the clock; a responder asking "is this hostile" should read the diff.

4.3 Why an intent AUC of 0.90 is a trap

Figure 3B is the panel we expect most pipelines to publish. Feed timing features to a classifier and ask it for intent, and it returns AUC 0.90 — an excellent-looking number. It is almost entirely the leash wearing intent's clothes. Three of the five classes are non-benign and they sit at three different leash settings; the two benign classes sit at two others. Timing reads the leash at ρ = 0.95, and the taxonomy supplies the rest. Hold the leash fixed — compare the non-benign loose human against the benign loose human, who differ in nothing observable except what they touch — and the same features fall to 0.48.

The same confound runs the other way, more weakly: target features pick up ρ = 0.17 for the leash across all five classes, and 0.10 once intent is fixed. Any real incident dataset will have this entanglement, because non-benign actors are not a random sample of leash settings. A pipeline that does not hold one axis fixed will report the other axis and call it detection.

Practical readingAn intent classifier built on behaviour and validated on a mixed fleet is measuring the fleet's composition. Re-run it on a matched subset before you believe it.

4.4 Under disguise a pair collapses, and a frozen model inverts

At L1 an autonomous agent waits before every action and asks for permission first. On timing alone it is then indistinguishable from a close human: pairwise AUC 1.00 at L0, 0.51 at L1 — chance, and confirmed by an explicit two-class test between a rogue agent at L1 and a close human at L0 (0.58). At L2 the human auto-approves; now every class looks unsupervised, and the ordinal read-out falls from 0.95 to 0.16. Neither move requires an exploit. The first costs the attacker waiting time; the second costs the defender nothing at all.

Figure 4 is the part we would put in front of anyone deploying such a model. Retrained at each level, timing holds up surprisingly well — a mixture weight is still a mixture weight. But a detector frozen at L0 does not decay toward chance. It falls to ρ = +0.18 at L1, −0.12 at L2, and −0.72 at L3, when both sides have swapped discipline: it has learned the sign of the relationship, and the sign is now wrong.

The failure mode to fearA model that reports "supervised, benign-looking workflow" with high confidence about an autonomous, non-benign one is worse than no model at all, because nothing in its output says so.

4.5 The price list

Attribution work usually stops at "the classifier can be fooled". The more useful question for a defender is what the fooling costs the fooler. All three numbers below are measured from the generated traces, not assumed:

  • Waiting is expensive. To look supervised, the autonomous agent at L1 waits a median of 42 s before every action: mean delay rises from 1.2 s to 60.0 s per action. With an action every two minutes, that is a 49% throughput tax on every step of the campaign.
  • Camouflage costs capability. At L4 the non-benign actors touch sensitive paths 34% of the time, and 13% when dressed as ordinary work. The disguise works — target intent AUC falls from 0.95 to 0.53, i.e. to chance — because the actor gave up most of what made it worth detecting.
  • Delegation is free for the attacker. At L2 the human auto-approves and pays nothing; the cost lands on the defender's oversight. This is the cheapest evasion in the ladder and the only one that needs no adversary — just a default setting.

4.6 How much behaviour before you can say anything?

Incident response has a clock. Figure 5 asks how discrimination grows with the number of actions observed. The leash is readable from about ten actions (ρ = 0.91) and saturates by forty; intent from targets climbs more slowly, because file choices are noisier than waiting times, and needs roughly eighty actions to reach 0.96. Waiting for more data does help — while the channel still carries the signal.

The disguised fleet is the interesting exception. At L3 both curves stay high, but not because the model got better: once discipline itself is correlated with intent, a leash detector becomes an intent detector for free. That is Section 4.3's confound returning in adversarial dress, and it is the strongest argument for the matched comparison in Figure 3C: a number that survives at L3 may be measuring the disguise, not the actor.

5. What a responder should do with this

  1. Report the mixture, not the label. "38% of actions waited for a human, median 41 s, n = 214" is defensible and auditable. "This was a supervised human" is not. Refuse the label even when the classifier is confident — especially then.
  2. Hold the other axis fixed before believing an intent number. If a model separates benign from non-benign, re-run it on actors with the same leash. If the number collapses, the model was reading supervision.
  3. Never deploy a frozen behavioural model without a matched-pair audit. The L3 failure is not a subtle drift; it is a sign flip. Ship the audit with the model: can it still separate the two classes it was trained on, on this month's traffic? If not, fail closed.
  4. Prefer the channel the adversary cannot choose. Timing and targets are both self-reported. Attestation — a signed agent identity, an operator registry entry — is the only channel in the brief that binds a claim to a party. Behaviour tells you where to look. It does not tell you who to call.

6. Limitations

This is a simulator. Traces come from an explicit model of supervision, not from recorded deployments. The model is stated in Section 2 and implemented in src/gen.ts in fewer than two hundred lines; where it is wrong, our numbers are wrong in a way a reader can check. The most fragile assumption is that a human's influence appears as a per-action wait. Real supervisors intervene in bursts, edit the plan rather than the action, and leave traces in channels we do not model — issues, chat, calendar. That assumption flatters timing if anything: bursty supervision would be easier to spot, and easier to imitate.

No real LLM traces. The organisers' held-out set is not available to us, so there is no leaderboard number here and we do not imply one. Our claim is about the shape of the problem, not about a particular model's behaviour.

Two channels only. Identity probes and attestation are discussed but not built. The obvious next experiment is to add a probe channel and run it up the same ladder; our prediction, which we have not tested, is that probes inherit the same weakness — they are behaviour the adversary can rehearse — while attestation does not.

Modest scale. 600 traces per level, 102470 events, five folds. Enough to see a sign flip; not enough to certify a small difference.

7. Reproducibility

Everything in this report comes from one command on a clean clone: npm ci && npm run build && npm run run && npm run verify. The L0 dataset hash is 8cd1542a484a8b54…; regenerating it elsewhere reproduces every figure. verify.mjs implements AC-01–AC-15 from SPEC.md: determinism, no leakage through the feature API, grouped folds, a measured chance floor, the direction of every claim we make, the rule that the report is a pure function of results.json (editing a number by hand makes the build fail), and the page budget.
