Discipline is a choice

An identifiability analysis of behavioural agent attribution — and what a disguise costs
Submission to the Agent Attribution Hackathon (Apart Research, 11–13 December 2026) · Track 2, Attribution · Code and every number in this report: github.com/hkmpn9s6dh-commits/hackathon-2026-attribution · 20 November 2026
Abstract. A responder at an agent incident needs a fact the logs do not contain: is a human steering this, and how tightly? We build an executable testbed from the five actor types in the sprint brief — two observable channels (when the agent acts, what it touches), five discipline levels, 150 actors and 600 traces per level, actors kept whole across folds. On it we demonstrate three things. First, an identifiability result: when supervision shows up only as a mixture weight, timing recovers the leash (ρ = 0.95 [0.94, 0.97]) and carries no intent signal once the leash is fixed (AUC = 0.48 [0.38, 0.58]); target choice shows the mirror image (AUC = 0.95; leash ρ = 0.10). Second, an evaluation trap: without holding the leash fixed the same timing features report intent AUC = 0.90 — the confound, not the hand. Third, a price list with a warning: an agent that waits like a supervised one becomes indistinguishable from one (pairwise AUC 1.00 → 0.51) at 60 s of added latency per action; camouflage collapses intent detection from 0.95 to 0.53 for 63% of the sensitive surface; and a detector fitted on the honest fleet does not decay — it inverts (ρ = -0.72 [-0.80, -0.65]).
What this is, and what it is not This is a simulator, and the identification is an identity of the construction, not an estimate from deployed agents. That is the point: it is the cheapest way to show what a detector can possibly recover when supervision is real but only weakly observable, and to put a number on the disguises. The two claims that do not depend on our generator are (i) the confound in Section 4.3 — any labelled fleet whose leash and intent are correlated as the brief's taxonomy makes them will inflate a behavioural intent score — and (ii) the inversion in Section 4.4, which follows for any monotone "who is in the loop" detector once the roles swap. Everything else is a demonstration, and Section 6 says what would break it.

1. The question, and why it is not academic

When an agent shows up in an incident — a supply-chain commit, an escaped process, a run that spent money — the first question a responder asks is not "which model" but "who, if anyone, is steering it". A human reachable by phone, a human who has not opened the logs in a week, and an agent nobody is watching call for three different responses: contact, escalation, containment. Today the three look alike from the outside, because in all three cases the text was written by the AI. Text detectors and assistant fingerprinting inherit that blindness: they classify the model, not the hand on the leash [1,3].

The sprint brief proposes three ways out: causal timing, identity probes, vendor attestation [2]. This report is about the first. Its existing evaluations are of the form "does the classifier separate the classes we drew?"; ours asks the prior question — what is identifiable at all, and at what price does an adversary make it unidentifiable?

2. Testbed: what is observable, and what is only latent

We implement the brief's five actor types (Table 1). What makes the problem hard is not the number of classes. It is that the classes differ along two axes — how tight the leash is (ordinal: 0 = nobody steering, 3 = a human on every step) and whether the human is benign (a binary we never observe) — and the two axes are entangled in the label (Table 2), which is exactly how a naive score gets flattered.

Population. 30 actors per class, 150 actors per level, four traces each (600 traces), 102470 events. One actor is one org; an actor's four traces never straddle a train/test boundary, so every score is about an actor the model has not met. Intervals are bootstrap over actors (400 resamples), not over traces.

A trace is a sequence of events over a 3–5 hour window: inbound messages, and actions carrying a tool (edit, read, shell, commit, net), a target path, a payload size and a shell-chain length. An action either waits for a human — it lands a human-latency interval after its scheduled tick, usually after a request message — or it does not. The share of actions that wait is the mixture weight p: the only thing that separates the actor types in the timing channel, and what a responder means by "tightly supervised".

Three design decisions carry the report. First, timing and content are generated by separate random streams: with one stream, drawing a different target file shifts every later draw and leaks the label into the timing, and a first version of this testbed did exactly that (a timing-only classifier scored AUC 0.90 on intent for no reason a responder could act on). Second, no event carries a label — there is no approved_by field, because a detector that can read it is not a detector. Third, tools follow targets, not labels: a workflow file gets edited, a key gets read. Wherever a class signature leaked into a second statistic, the leak looked like a great result.

3. Method

Features. Thirteen timing features (inter-arrival median and 90th percentile, coefficient of variation, binned entropy, Fano factor over minute buckets, phase concentration on the 60 s grid, latency after an inbound message at three cut-offs, coverage, share of gaps over five minutes) and ten target features (share of actions on sensitive paths — CI workflows, keys, registry config, install hooks — directory entropy, target diversity, tool mix, shell-chain length, edit size). No feature sees a label, an org id or a scenario id.

Models. Multinomial logistic regression and a small gradient-boosted tree ensemble (depth 2, 45 rounds, deterministic), each with three heads: the five-way label, the ordinal leash, the intent flag. Trees are included because a linear model could understate what a flexible detector can do; they agree closely, so the ceiling here is the channel, not the model.

Evaluation. Five-fold cross-validation grouped by actor; likelihood-free chance floor from 20 label permutations across actors (ρ = -0.04, AUC = 0.45). Headline numbers carry actor-bootstrap 95% intervals.

Ladder. L0 is the honest fleet. Four moves follow (Table 3), each generated from the same seeds as L0: the same actor does the same job with a different discipline, so the comparison is paired. We also score a detector frozen at L0 on every level — the deployment that actually happens, a model fitted on last quarter's incidents.

Matched comparisons. Because the claim is about what a channel can identify, we compare classes that share one axis: the two loose classes (C and E) for intent, the three non-benign classes for the leash, and two pairs that share a mixture weight outright (a rogue at L1 against a close human at L0; an auto-approving human at L2 against an autonomous agent at L0).

4. Results

4.1 Five-way accuracy is the wrong scoreboard

On the honest fleet the five-way problem is nearly solved: macro-F1 0.93, with residual error between the two classes that share a leash setting (Figure 2). That number says a classifier can reproduce the taxonomy on data from the same generator. It says nothing about whether the quantity is stable, which channel is doing the work, or what happens when the observed party stops cooperating — which is the rest of this section.

4.2 The clock knows the leash; the file paths know the hand

Figure 3(i) is the identifiability result. Timing recovers the leash at ρ = 0.95 [0.94, 0.97]; target features are nearly blind to it (ρ = 0.17). Figure 3(iii) holds the leash fixed and compares benign against non-benign actors: targets separate them at AUC 0.97, timing at 0.48 — chance.

This is what the construction guarantees, and what we wanted to show rather than assume: if supervision enters behaviour only as a share of waiting actions, then a timing detector can at best estimate that share. The value is in the demonstration being executable and in the price attached to changing the share (Section 4.5). A real deployment would also see supervisors who intervene in bursts, edit plans rather than actions, or leave traces in chat; we return to that in Section 6.

4.3 Why an intent AUC of 0.90 is a trap

Figure 3(ii) is the panel we expect most pipelines to publish. Feed timing features to a classifier and ask for intent, and it returns AUC 0.90. It is almost entirely the leash wearing intent's clothes. Three of the five classes are non-benign and they sit at three different leash settings; the two benign classes sit at two others (Table 2). Timing reads the leash at ρ = 0.95, and the taxonomy supplies the rest. Hold the leash fixed — compare C against E, which differ in nothing observable except what they touch — and the same features fall to 0.48.

The same confound runs the other way, more weakly: target features pick up ρ = 0.17 for the leash across all five classes, and 0.10 once intent is fixed. Any labelled fleet will have this entanglement, because non-benign actors are not a random sample of leash settings. A pipeline that does not hold one axis fixed will report the other axis and call it detection.

Practical readingAn intent classifier built on behaviour and validated on a mixed fleet is measuring the fleet's composition. Re-run it on a matched subset before you believe it.

4.4 Under disguise a pair collapses, and a frozen model inverts

At L1 an autonomous agent waits before every action and asks for permission first. On timing alone it is then indistinguishable from a close human: pairwise AUC 1.00 at L0, 0.51 at L1 — chance, confirmed by an explicit two-class test between a rogue agent at L1 and a close human at L0 (0.58).

L2 is a different kind of event and should be described as such: when the human auto-approves, the supervision is not hidden, it is gone. The ordinal read-out falls from 0.95 to 0.16 because there is nothing left to read, and that is the point — the cheapest way to become unattributable is to stop supervising, and it costs the defender a configuration change rather than the attacker an exploit.

Figure 4 is the part we would put in front of anyone deploying such a model. Retrained at each level, timing holds up surprisingly well — a mixture weight is still a mixture weight. But a detector frozen at L0 does not decay toward chance. It falls to ρ = 0.18 at L1, -0.12 at L2, and -0.72 [-0.80, -0.65] at L3, when both sides have swapped discipline: it has learned the sign of the relationship, and the sign is now wrong.

The failure mode to fearA model that reports "supervised, benign-looking workflow" with high confidence about an autonomous, non-benign one is worse than no model, because nothing in its output says so.

4.5 The price list

Attribution work usually stops at "the classifier can be fooled". The more useful question for a defender is what the fooling costs the fooler. Three numbers, all measured from the generated traces:

  • Waiting is expensive in latency, not volume. To look supervised, the autonomous agent at L1 waits a mean of 60.0 s before each action (median wait 42 s), against 1.2 s at L0. Its action count per hour is unchanged (30.1 vs 30.2) because in this model ticks keep firing; a deployment that serialised the agent behind each approval would instead lose about a third of its throughput at a two-minute cadence. We report the latency, and flag the throughput figure as conditional.
  • Camouflage costs capability. Non-benign actors touch sensitive paths 34% of the time at L0 and 13% at L4: a 63% relative drop. Intent detection from targets falls from 0.95 to 0.53 — chance — because the actor gave up most of what made it worth detecting.
  • Delegation is free for the attacker. At L2 the human auto-approves and pays nothing; the cost lands on the defender's oversight. It is the only move in the ladder that needs no adversary at all.

4.6 How much behaviour before you can say anything?

Incident response has a clock. Figure 5 asks how discrimination grows with the number of actions observed. The leash is readable from about ten actions (ρ = 0.91) and saturates by forty; intent from targets climbs more slowly, because file choices are noisier than waiting times, and reaches 0.96 by eighty actions.

The disguised fleet is the instructive exception. At L3 both curves stay high, not because the model got better: once discipline is correlated with intent, a leash detector becomes an intent detector for free. That is Section 4.3's confound returning in adversarial dress, and it is the strongest argument for the matched comparison in Figure 3(iii) — a number that survives at L3 may be measuring the disguise, not the actor.

5. What a responder should do with this

  1. Report the mixture, not the label. "38% of actions waited for a human, median 41 s, n = 214" is auditable. "A supervised human did this" is not. Refuse the label even when the classifier is confident — especially then.
  2. Hold the other axis fixed. Before believing an intent number, re-run it on actors with the same leash. If it collapses, it was supervision.
  3. Never deploy a frozen behavioural model without a matched-pair audit. The L3 failure is not subtle drift; it is a sign flip. Ship the audit with the model and fail closed when it stops separating the classes it was trained on.
  4. Prefer the channel the adversary cannot choose. Timing and targets are both self-reported. Attestation — a signed agent identity, an operator registry entry — is the only channel in the brief that binds a claim to a party. Behaviour tells you where to look, not who to call.

6. What would falsify this, and other limits

The invariance is ours. Section 4.2 holds because supervision enters the trace only as a per-action wait. Real supervisors do something else as well: they intervene in bursts, edit the plan rather than the action, respond faster to risky actions, and leave traces in channels we do not model. Each of those would give timing a genuine intent signal — and would also make a competent attacker's job harder. The experiment that would break our claim is a real trace set in which human latency depends on the action's content; we cannot run it here, and we would expect it to raise the matched timing AUC above chance. Our number is the floor for that experiment, not its answer.

No real LLM traces. The organisers' held-out set is not ours, so there is no leaderboard number here and we do not imply one.

Two channels only. Identity probes and attestation are discussed, not built. Our prediction — untested — is that probes inherit the same weakness, since a probe is behaviour the adversary can rehearse; attestation does not.

Modest scale. 150 actors per level, five folds. Enough to see a sign flip and to bound it with an interval; not enough to certify a small difference.

7. Reproducibility

Everything here comes from one command on a clean clone: npm ci && npm run build && npm run run && npm run figs && npm run report && npm run verify. The L0 dataset hash is 8cd1542a484a8b54…; regenerating it elsewhere reproduces every figure. verify.mjs implements AC-01–AC-15 from SPEC.md: determinism, no leakage through the feature API, actor-grouped folds, a measured chance floor, the direction of every claim, the rule that the report is a pure function of results.json (editing a number by hand fails the build), and the page budget. Runtime, 347 s on a laptop, no GPU.
